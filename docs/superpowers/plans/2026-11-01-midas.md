# MIDAS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, user waived review) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Personal finance app: iPhone double-tap screenshot → auto transaction, plus mobile dashboard with budgets and accounts.

**Architecture:** One Node process on 127.0.0.1:5003 serves `public/` and `/api/*`. SQLite via `node:sqlite`. Balances/budget are computed from transactions. Capture saved raw, then extracted by `claude -p` (injectable runner so tests use a fake).

**Tech Stack:** Node 24 (`node:sqlite`, `node:http`, `node:test`), vanilla HTML/JS/CSS. No dependencies.

**Spec:** `docs/superpowers/specs/2026-11-01-midas-design.md`

## Global Constraints

- No npm dependencies; run with `node --env-file=.env server.js`; port **5003**, host **127.0.0.1**.
- Money = integer rupiah; dates ISO `YYYY-MM-DD`; "today" computed in `Asia/Jakarta`.
- Balances and budget used are **computed**, never stored.
- `/api/capture` needs `Authorization: Bearer $MIDAS_TOKEN`; everything else needs a session cookie from `POST /api/login {password}` (`$MIDAS_PASSWORD`). `.env` is gitignored.
- Capture low confidence (< 0.7) or unknown category/account → transaction created with `flag='review'`.
- Tests: `node --test`; a test file per module in `test/`.

## Review Focus

- Edit/delete a transaction → balance and budget change accordingly (computed, so tested in calc).
- Transfer between accounts: from decreases, to increases, never counted as expense in budget/stats.
- Liability account (Mortgage/Paylater): expense makes balance more negative; totals split Assets vs Liabilities.
- Recurring on day 31 in a 30-day month runs on the last day, and never twice in one month (restart-safe).
- Capture: Claude returns invalid JSON/times out → capture `failed`, nothing lost, no crash; wrong/missing token → 401 with no write.

### Task 3: Auth + API CRUD

**Files:** Create `src/auth.js`, `src/api.js`, `test/api.test.js`

**Interfaces:** Produces `createApp(db, {token, password, runClaude, dataDir}): (req,res)=>void`. Auth: `POST /api/login {password}` sets HMAC-signed `midas` cookie (HttpOnly, SameSite=Lax); 401 otherwise. REST JSON: `GET|POST /api/accounts`, `/api/groups`, `/api/categories`, `/api/recurring`, `/api/transactions?month=YYYY-MM`; `PUT|DELETE /api/<res>/:id`; `GET /api/summary?month=` → `{totals, accounts:[{...,balance}], budgets}`. Unknown route → 404 JSON. Static files from `public/` served for non-`/api` GET (path traversal rejected).

- [ ] **Step 1:** Tests via `http.createServer(createApp(...)).listen(0)`: unauthenticated `/api/summary` → 401; login then create account → 201, list shows it; POST transaction then PUT amount → summary balance updates; DELETE transaction → balance reverts; `GET /../etc/passwd` → 404/400.
